# Ideas

Skill ideas not yet built. Promote one by brainstorming it into a spec under
`docs/specs/`, then a draft under `drafts/`.

## pre-mortem

Imagine the project has already failed spectacularly, then work backward to the
causes. "Prospective hindsight" surfaces risks that asking "what could go wrong?"
misses. The skill declares the project dead in the future tense, writes the
autopsy, and turns each cause into a mitigation. (Klein; surfaced in the
creativity-catalyst sweep, 2026-06-22.)

## Backlog

Other candidates from the same sweep — one line each, lowest commitment:

- **generic-parts decompose** — relabel parts by shape/material to break functional fixedness.
- **conceptual blend** — fuse two domains, elaborate the hybrid for what neither parent had.
- **flow / calibrate** — tune challenge-to-skill, sharpen the goal, tighten the feedback loop.
- **incubation / defer** — refuse to grind; assign an unrelated task and schedule a return pass.
- **Oulipo constraint** — generate under an arbitrary formal rule.
- **Fluxus event score** — a terse instruction you perform in the world.
- **yes-and improv** — affirm and extend every offer (the inverse of grill-me).
- **finite vs infinite games** — "playing to win, or to keep playing?"
- **first-principles** — strip to irreducibles, rebuild up.
