# skills

A personal collection of agent skills by [Nathan Toups](https://n.2p5.xyz/) (n2p5), centered on
infinite games and autotelic pursuits — creativity, play, and thinking well.

## What's here

- **[oblique-strategies](skills/oblique-strategies/SKILL.md)** — draw a
  random lateral-thinking card when you're stuck, and read it against the
  problem.
- **[rubber-duck](skills/rubber-duck/SKILL.md)** — a listener that asks
  questions and reflects your thinking back, refusing to solve until you ask.

## Install

```sh
# Skills CLI — pick what you want; installs unprefixed, e.g. /oblique-strategies
npx skills add n2p5/skills
```

Or as a Claude Code plugin — the whole set, under the `/n2p5:` prefix:

```text
/plugin marketplace add n2p5/skills
/plugin install n2p5@n2p5-skills
```
